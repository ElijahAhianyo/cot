## Share your project

Built something with Cot? Start a [GitHub discussion](https://github.com/cot-rs/cot/discussions) to introduce it and suggest an entry for this showcase. A small tool or a learning project can be useful to other developers too.

Include:

- **Project name and link:** a public website, repository, or demo.
- **What it does:** one or two sentences about the problem it solves.
- **Where Cot fits:** the whole application, an API, or another backend component.
- **Project stage:** an experiment, a learning project, or an application people can use.
- **Who to credit:** the person or team and a public profile link, if desired.

Source code is useful for readers who want to learn from the implementation. If the source is private, describe Cot’s role without sharing credentials, private data, or internal links.

## Keep an entry useful

If your project moves, changes direction, or is archived, suggest an update with the new link or status. An accurate short description is more helpful than an old claim about features the project no longer offers.

For help with Cot itself, visit [Community and contributing](../overview/). For examples you can run while learning the framework, start with the [tutorials](../../tutorials/overview/).
